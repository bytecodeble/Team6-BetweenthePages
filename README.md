# **Between the Pages – 2D Action Platformer Prototype**

## Overview

Single-player 2D action-platformer prototype built in **Unity 6000.2.4f1**.

The player is pulled into a cursed storybook and must journey through corrupted fairy tales, battling darkened characters to restore the collapsing world.  

**Playable Build:**  
[https://astacreates.itch.io/between-the-pages](https://astacreates.itch.io/between-the-pages)

**Trailer:**  
[https://youtu.be/RUB26VliWFI](https://youtu.be/RUB26VliWFI)

## How to Run

### Option 1 (Suggested) – Play the build

Play the Windows build via Itch.io link above.

### Option 2 – Run in Unity

1. Clone the repository
    
2. Open with **Unity 6000.2.4f1**
    
3. Open the main scene
    
4. Press Play
